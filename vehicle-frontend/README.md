# VehicleFrontend

Проект был создан с помощью:
- Angular 20
- NgRx (Redux для Angular)
- SCSS
- Angular Animations
- Angular Material

Как сконфигурировать:
Пререквизит: npm -v == 20

```
npm install
```
Как построить проект:

```ng build```

(Потом можешь закинуть папку с `html, js & css` на `public_home`, чтобы иметь фронт на гелиосе)

Как запустить (локально):

```ng serve```
